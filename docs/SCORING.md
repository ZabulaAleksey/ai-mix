# Оценивание

## Фрагмент
`score = w1*salience + w2*energy + w3*hook + w4*boundary_conf + w5*tonal_stability + w6*rhythmic_stability + w7*loudness_consistency - w8*vocal_overlap_risk`

Веса задаются конфигурацией, а не жёстко зашитым бизнес-правилом.

## Переход
Используй детализацию вместо единственной «магической» метрики:
- разница темпа;
- гармоническое расстояние и расстояние между тональностями;
- выравнивание фаз долей;
- совместимость границ фраз;
- наклон энергии;
- спектральная перегруженность;
- наложение вокала;
- стоимость обработки изменения длительности и высоты тона.

Сохраняй детализацию для объяснения «Почему?» в UI.
