# Историческая инструкция запуска этапов

Исходный `prompts/README.md` сохранял следующий stage workflow. Для live
execution используй только выбранный record `docs/STAGES.md`:
1. читает необходимый контекст;
2. определяет объём работы и то, что не входит в цели;
3. вносит минимальные изменения;
4. запускает тесты и benchmarks;
5. обновляет выбранный `docs/STAGES.md` record, а при необходимости — `DEV_LOG.md`, `LEARNING.md`, `docs/DECISIONS.md`;
6. останавливается на границе этапа.

Единственный источник этапов и текущего состояния — `docs/STAGES.md`.
Не передавай весь файл Codex без необходимости; попроси выполнить выбранный
этап по stable ID.
