# PROMPT 07 — таймлайн и рендеринг

Реализуй версионируемое неразрушающее состояние таймлайна и план рендеринга FFmpeg/Rubber Band.

Исходные аудиофайлы всегда остаются неизменными.

Каждый элемент таймлайна должен явно хранить две системы координат:
- `source_start/source_end` — точное положение фрагмента в исходном треке;
- `mix_start/mix_end` — точное положение этого фрагмента в итоговом миксе.

Timeline должен хранить:
- ссылку на исходный media asset;
- выбранный fragment/segment;
- порядок фрагментов;
- overlap между соседними фрагментами;
- параметры переходов;
- gain/fades/envelopes, если они нужны рендереру;
- time-stretch и pitch операции;
- источник значения: AI recommendation или manual override;
- locked state для фрагментов и переходов.

Ручное изменение одного элемента не должно сбрасывать остальные ручные изменения. Undo/redo и версионирование должны работать на уровне неразрушающей модели проекта.

Поддержи план частичного пересчёта: незакреплённая часть timeline может быть заменена новым результатом optimizer'а без изменения locked элементов.

Добавь проверки:
- корректности source/mix time ranges;
- общей длительности;
- overlap;
- clipping;
- отсутствия модификации исходных файлов;
- детерминированности render plan для одинакового состояния проекта.

Рендеринг должен позволять получить WAV/FLAC и сериализуемое описание проекта/timeline для последующего редактирования и будущего Adobe Audition workflow.

DoD:
- source-time и mix-time представлены явно и тестируются;
- manual overrides и locked state переживают сериализацию/восстановление;
- повторный расчёт незакреплённой части не повреждает принятые пользователем решения;
- render plan проверяет clipping и длительность;
- исходные файлы не изменяются.
