# PROMPT 08 — минимальный GUI AI Mix Assistant

Реализуй GUI строго по `DESIGN.md` как компактное профессиональное desktop workspace, а не как полноценную DAW.

Основной экран должен состоять из трёх постоянных зон:

1. **Треки** — список добавленных композиций с названием, исполнителем при наличии, BPM, key, duration и status анализа.
2. **Предложение микса** — компактное «Как выбрал AI», посекундный timeline с waveform, source-time и mix-time выбранных фрагментов.
3. **Переход** — контекстный инспектор выбранного стыка с редактируемыми параметрами перехода и preview.

Обязательные пользовательские действия:
- добавить треки;
- запустить/увидеть статус анализа;
- получить AI-предложение;
- открыть объяснение «Почему?» для выбранного фрагмента/перехода;
- видеть точные source start/end и mix start/end;
- изменить порядок фрагментов;
- изменить границы фрагмента;
- выбрать переход;
- изменить тип перехода, fade, overlap, time-stretch, pitch и EQ smoothing;
- видеть отличие AI-рекомендации от manual override;
- вернуть параметр к AI-рекомендации;
- закрепить фрагмент/переход;
- пересчитать незакреплённую часть или «пересчитать отсюда»;
- прослушать выбранный переход в loop/preview;
- прослушать итоговый микс;
- экспортировать результат.

Показывай предупреждения о vocal overlap, clipping risk, чрезмерном stretch/pitch и низкой уверенности анализа компактно и контекстно.

Не выноси подробные DSP-метрики на основной экран. Chroma, spectral features, confidence breakdown и другие внутренние признаки доступны через `Почему?` / `Подробнее`.

Визуальная семантика:
- голубой — DSP/совместимость/техническая информация;
- фиолетовый — AI-рекомендация;
- янтарный — риск/предупреждение.

Не добавляй без отдельного требования:
- dashboard;
- тарифы/регистрацию;
- marketplace;
- социальные функции;
- большой классический mixer;
- VST rack;
- multitrack recording;
- mastering suite;
- node editor;
- постоянно открытый AI-chat;
- десятки дополнительных панелей.

UI не должен содержать DSP или бизнес-логику: он работает через application/core interfaces и отображает состояние доменной модели.

DoD:
- основной сценарий выполняется без перехода между множеством экранов;
- UI соответствует трёхколоночной структуре из `DESIGN.md`;
- AI recommendations объяснимы и визуально отличимы от manual overrides;
- переходы редактируются и быстро прослушиваются;
- locked elements и partial recalculation доступны из GUI;
- нет функций полноценной DAW вне согласованного scope;
- добавлены component/integration tests для ключевых UI-состояний и сценариев.
