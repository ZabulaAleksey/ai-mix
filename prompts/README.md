# Prompts

Use one prompt at a time. Each prompt:
1. reads required context;
2. states scope/non-goals;
3. makes minimal changes;
4. runs tests/benchmarks;
5. updates `PROGRESS.md`, and when appropriate `DEV_LOG.md`, `LEARNING.md`, `docs/DECISIONS.md`;
6. stops at stage boundary.

Do not paste the whole file to Codex unless needed; ask it to execute the named prompt.
