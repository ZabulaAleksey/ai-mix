# Prompts

Используй по одному prompt за раз. Каждый prompt:
1. читает необходимый контекст;
2. определяет объём работы и то, что не входит в цели;
3. вносит минимальные изменения;
4. запускает тесты и benchmarks;
5. обновляет `docs/AI_STATUS.md`, а при необходимости — `DEV_LOG.md`, `LEARNING.md`, `docs/DECISIONS.md`;
6. останавливается на границе этапа.

Единственный подробный источник этапов — `STAGES.md`. Не передавай весь файл Codex без необходимости; попроси выполнить этап по имени.
